# Свитки проклятого снаряжения

Свитки распознавания и снятия проклятий создаются только у арканического стола и имеют восемь уровней качества. Уровень определяется навыком Inscription относительно диапазона навыка рецепта. Качество сохраняется при перезапуске и отображается в свойствах свитка.

Шанс применения зависит от Evaluating Intelligence и Inscription персонажа, качества свитка и сложности предмета. Уровень качества добавляет до 35 процентных пунктов к шансу; итоговый шанс ограничен диапазоном 5–95%. Для распознавания сложность растет с редкостью предмета. Для снятия проклятия учитываются сила проклятия и редкость.

Снятие проклятия с артефактов по-прежнему требует Evaluating Intelligence выше 120.0 либо выше 110.0, если в мире находится Аватар; после этой проверки успех определяется шансом свитка и навыков, а не гарантируется автоматически.

Шанс выпадения настраивается в `Config/Loot.cfg` параметрами `MageIdentificationScrollDropChance` и `MageRemoveCurseScrollDropChance` (проценты; по умолчанию 2%). Удача может дать дополнительную попытку броска. Выпадение обрабатывается событиями сервера в пользовательском скрипте `CurseScrollLoot`, без изменений `LootPack.cs`.
