# KarmaVirtue

## Влияние алтарей на города и подземелья

Связь задается в массиве `Shrines` в `KarmaVirtueManager.cs`: для каждого алтаря указываются имя региона города и имя региона подземелья. Имя может совпадать с родительским регионом, поэтому эффект действует и во вложенных регионах.

Последняя активация каждого алтаря определяет его глобальное состояние и сохраняется отдельно от персональных записей игроков. Светлый алтарь повышает прирост развития связанного города, уменьшает лимит монстров в подземелье и увеличивает время их респауна. Он также снижает шанс вторжения в связанный город на 25%; оскверненный алтарь увеличивает этот шанс на 25%. Множители нескольких алтарей, связанных с одним городом (например, Британией), перемножаются.
